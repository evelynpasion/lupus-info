# Yo puedo con el lupus

Este proyecto es un **sitio web informativo** sobre el lupus, creado para explicar qué es el lupus, síntomas, diagnóstico, tratamiento y brindar recursos de importancia. 

---

## Objetivos
- Presentar información accesible, comprensible y organizada para visibilizar esta enfermedad.
- Explicar el lupus de forma sencilla.
- Acompañar a través del conocimiento a quienes buscan entender mejor su diagnóstico.
- Practicar la estructura semántica con **HTML5**.
- Diseñar una interfaz responsiva usando **Bootstrap**.
- Integrar **buenas prácticas de accesibilidad web**.

---

## Tecnologías utilizadas
- **HTML5**
- **Bootstrap**

---

## Accesibilidad
Este sitio incluye:
- Uso adecuado de etiquetas **HTML semántico**
- Encabezados organizados en un orden lógico
- Enlaces con texto descriptivo
- Imágenes decorativas con `alt=""` para que los lectores de pantalla las omitan
- Navegación simple y estructura clara
- Uso básico de atributos **ARIA** para mejorar la experiencia con lectores de pantalla
